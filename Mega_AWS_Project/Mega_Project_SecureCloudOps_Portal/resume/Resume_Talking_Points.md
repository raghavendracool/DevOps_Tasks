# Resume Talking Points

## Project Title

**SecureCloudOps Portal — Highly Available AWS Three-Tier Application and SecOps Platform**

## Resume Bullets

- Designed and deployed a highly available AWS three-tier application using VPC, public/private subnets, ALB, Auto Scaling, private EC2, and Amazon RDS MySQL.
- Developed a React frontend and FastAPI backend supporting authentication, S3 file upload/download, private user prefixes, and presigned download URLs.
- Implemented event-driven AWS Lambda automation to classify finance and non-finance files uploaded to S3.
- Built CloudTrail and EventBridge security detections for IAM user creation, access-key creation, IAM deletion, S3 bucket deletion, and critical logging changes.
- Developed scheduled compliance checks for EC2 tags, EBS encryption, and IAM key age, publishing custom CloudWatch metrics to Grafana dashboards.
- Automated infrastructure provisioning with Terraform and CloudFormation and validated code through GitHub Actions CI.
- Applied least-privilege IAM, encrypted EBS/RDS/S3 storage, private database networking, S3 Block Public Access, and Systems Manager-ready EC2 roles.
- Documented troubleshooting runbooks, cost optimization, scaling tests, cleanup procedures, and production improvement recommendations.

## Tools

AWS, Terraform, CloudFormation, EC2, ALB, Auto Scaling, RDS MySQL, S3, Lambda, EventBridge, CloudTrail, CloudWatch, SNS, IAM, Secrets Manager, Grafana, React, FastAPI, Docker, NGINX, GitHub Actions, Linux
