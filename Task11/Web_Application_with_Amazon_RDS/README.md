# Project 11 — Web Application with Amazon RDS

![Task 11 Architecture](infographic.png)

This project deploys a Flask web application on Ubuntu EC2 and connects it securely to an Amazon RDS for MySQL database.

## Project Requirements

- Create an Amazon RDS MySQL DB instance
- Install MySQL Workbench locally
- Connect using the RDS endpoint, database username and password
- Create an application database and restricted database user
- Configure the application with the new credentials
- Verify connectivity by registering and logging in
